# فاکتور ساز ویلی وب

افزونه فارسی و مدیریتی صدور فاکتور فروش و لیبل پستی سفارش‌های ووکامرس، ساخته‌شده توسط [WiliWeb](https://wiliweb.com).

## قابلیت‌ها

- چاپ تکی و گروهی فاکتور فروش و لیبل پستی از پیشخوان
- دو قالب فاکتور «مدرن فروشگاهی» و «رسمی کلاسیک»
- نمایش تصویر محصول، SKU، ویژگی‌ها، تعداد، قیمت، تخفیف و جمع‌های ووکامرس
- فعال یا غیرفعال‌سازی مستقل فاکتور، لیبل و اجزای هر خروجی
- دسترسی مدیر و مدیر فروشگاه، بدون نمایش فاکتور به مشتری
- سازگاری با HPOS و ساختار قدیمی سفارش‌های ووکامرس
- چیدمان ۱، ۲، ۴، ۶ یا ۸ لیبل در A4
- جهت عمودی و افقی، قالب جدولی و ساده و فیلدهای قابل انتخاب
- انتخاب لوگو از کتابخانه رسانه وردپرس
- فونت وزیر داخلی و رابط راست‌به‌چپ
- لینک چاپ امضاشده و مستقل از transient و کش
- بروزرسانی بومی وردپرس از GitHub Releases

## نصب

فایل `woo-shipping-label-wiliweb-VERSION.zip` را از بخش [Releases](https://github.com/aheydarihd/woo-shipping-label-wiliweb/releases/latest) دریافت و از پیشخوان وردپرس نصب کنید.

نسخه 1.0.6 اولین نسخه دارای آپدیتر GitHub است؛ سایت‌هایی که نسخه قدیمی‌تر دارند باید این نسخه را یک بار دستی نصب کنند. نسخه‌های بعدی در پیشخوان وردپرس نمایش داده می‌شوند.

## انتشار نسخه جدید

1. نسخه را در هدر افزونه، ثابت `WSL_VERSION` و `readme.txt` تغییر دهید.
2. تغییرات را commit و روی شاخه `main` push کنید.
3. tag هم‌نسخه مانند `v1.1.1` بسازید و push کنید.
4. GitHub Actions فایل ZIP استاندارد و checksum را ساخته و Release را منتشر می‌کند.

صرفاً push کردن کد آپدیت جدیدی برای سایت‌ها منتشر نمی‌کند؛ انتشار Release با tag الزامی است.
