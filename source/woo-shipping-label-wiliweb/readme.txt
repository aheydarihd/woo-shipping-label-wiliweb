چاپ تکی و گروهی لیبل پستی سفارش‌های ووکامرس با قالب فارسی و چیدمان A4.

== Description ==

از صفحه سفارش یک لیبل و از فهرست سفارش‌ها چند سفارش را انتخاب و چاپ کنید.
تعداد لیبل در هر A4 می‌تواند 1، 2، 4، 6 یا 8 باشد و جهت خود لیبل بین عمودی و افقی تغییر کند.
لوگو مستقیماً از کتابخانه رسانه وردپرس انتخاب می‌شود. چاپ از فونت قالب فعال استفاده می‌کند و وزیر محلی داخل افزونه جایگزین آن است.
درخواست چاپ با امضای زمان‌دار ساخته می‌شود و به transient یا وضعیت کش وابسته نیست.
از نسخه 1.0.6، نسخه‌های جدید از GitHub Releases در بخش افزونه‌های وردپرس نمایش داده می‌شوند.

== Installation ==

1. فایل ZIP را از بخش افزونه‌ها بارگذاری و فعال کنید.
2. از ووکامرس ← لیبل پستی، اطلاعات فرستنده و چیدمان را تنظیم کنید.
3. برای چاپ گروهی سفارش‌ها را تیک بزنید و عملیات «چاپ لیبل پستی» را اجرا کنید.
